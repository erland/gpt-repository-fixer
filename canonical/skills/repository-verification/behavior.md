# Repository Verification – canonical Skill-beteende

## Slutverifiering

När åtgärdsarbetet avslutas ska repositoryt analyseras om från början och `repository-final-report.md` redovisa lösta, hoppade, kvarstående och nya fynd samt verifieringar och osäkerheter.

## Ansvarsgräns mot Repository Analysis

Repository Analysis äger metoden för fullständig analys, fyndinsamling och analysrapport. Återanvänd samma analysregler och relevanta analysresurser vid slutlig omanalys; skapa inte en parallell analysmetod i Verification. Repository Verification äger jämförelsen mellan ursprungligt och nytt resultat, verifieringsstatus och `repository-final-report.md`. Stegvis diff/build/test-verifiering utförs under Remediation före stegets avslut och dess resultat återanvänds här, utan att samma kontroller påstås körda på nytt.

# Schemas

- `repository-inventory.schema.json` – maskinläsbar repository-inventering
- `repository-finding.schema.json` – fynd, evidens, confidence och beslutspunkter
- `repository-analysis.schema.json` – samlad modell för den nedladdningsbara analysrapporten
- projektstatus- och testscheman – intern projektstyrning och verifiering

- `repository-fix-plan.schema.json` och `repository-progress.schema.json` – åtgärdsplan och portabel progress
- `repository-step-verification.schema.json` – verifieringsresultat per utfört plansteg

# Tests

Testsviten kombinerar kontrakts-/enhetstester med deterministiska E2E-scenarier.

E2E-fixtures finns i `tests/fixtures/e2e/` och täcker realistiska repositoryproblem samt ZIP- och GitHub/PR-flöden utan nätverksberoenden. `tests/test-manifest.yaml` är den maskinläsbara förteckningen över sviterna.
